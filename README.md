# Proyek Pemrograman Mobile

## Deskripsi
Aplikasi latihan untuk pembelajaran pemrograman berbasis mobile menggunakan Flutter.

## Pengembang
Nama panggilan / akun GitHub: ekabawa

## Status
Proyek awal perkuliahan.


## Tujuan

Mempelajari dasar-dasar pengembangan aplikasi mobile menggunakan Flutter serta menerapkan penggunaan Git dan GitHub dalam pengelolaan proyek.

## Rencana Fitur

1. Fitur tampilan antarmuka aplikasi mobile.
2. Fitur navigasi antarhalaman.
3. Fitur pengolahan dan penyimpanan data sederhana.

## Cara Menjalankan

1. Pastikan Flutter dan Git sudah terpasang.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan perintah `flutter pub get` pada terminal.
4. Jalankan aplikasi menggunakan `flutter run`.
